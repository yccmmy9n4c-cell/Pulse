# Linux Assessment navigation

Pulse Linux Beta 0.0.0.30 organizes the complete 48-provider assessment into three user-directed views.

| Overview choice | Included evidence | User meaning |
| --- | --- | --- |
| Information | `Informational` | System facts, baselines, optional posture, and context that do not request action |
| Healthy | `Healthy` | Evidence Pulse checked and found working as expected at assessment time |
| Guidance | `Attention`, then `Unavailable` | Review items first, followed by explained coverage limitations and safe next steps |

Every result is assigned exactly once. The organizer does not reinterpret provider state, change Dashboard scoring, remove report evidence, or alter assessment history.

The Linux Assessment navigation entry always opens the overview first. Each large button-card opens a dedicated evidence-card page, and each detail page provides **Back to Assessment**. When a domain action cannot open a supported native utility, Pulse routes directly to the matching filtered Assessment section.
