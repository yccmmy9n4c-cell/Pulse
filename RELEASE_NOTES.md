# Pulse Linux Beta 0.0.0.29

This build advances Pulse with dedicated Startup Intelligence while preserving the complete 0.0.0.28 Hardware Intelligence and Performance correction milestone.

- Adds a six-card Startup Intelligence page for boot duration, critical startup chain, failed system services, failed user services, XDG desktop autostart, and enabled user services/timers.
- Adds Startup Intelligence as the ninth evidence-backed Dashboard domain.
- Expands the assessment from 40 to 43 isolated providers by adding three Linux-native, read-only startup sources and reusing three accepted reliability sources.
- Offers a guided route to an installed desktop Startup Applications utility when one is available; Pulse never enables, disables, starts, stops, or removes startup items.
- Retains the explicit nullable battery-capacity declaration needed by the C# compiler, without changing the accepted 0.0.0.28 calculation or thresholds.
- Preserves automatic GitHub prerelease publication, checksum verification, coverage-neutral scoring, and every existing Pulse safety boundary.
